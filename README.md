# ✳ NEBULA — Generative Art Lab

> Universos que nunca se repetem.

NEBULA é um laboratório de arte generativa executado diretamente no navegador. Partículas, luz e movimento se combinam para criar composições cósmicas — sem frameworks, instalação ou dependências de runtime.

## Recursos

- Quatro estruturas visuais: galáxia espiral, nebulosa gasosa, constelações e buraco negro.
- Quatro paletas: Aurora Boreal, Nebulosa Violeta, Poeira Estelar e Silêncio Lunar.
- Controles de densidade e intensidade do brilho.
- Animação controlável e respeito à preferência de movimento reduzido do sistema.
- Acessibilidade: controles identificados, foco visível e interação com o canvas por teclado.
- Clique ou Enter/Espaço na tela para criar ondas de luz.
- Exportação PNG.
- Link reproduzível com seed, estrutura, paleta, densidade e brilho.
- Seed estável: redimensionar a janela não sorteia outro universo.
- Sem build ou dependências de runtime.

## Como executar

1. Clone ou baixe este repositório.
2. Abra index.html em um navegador moderno.
3. Escolha uma estrutura, paleta e ajuste os controles.

Para compartilhar uma composição com outras pessoas, publique o projeto em HTTPS (por exemplo, GitHub Pages). Links locais file:// não funcionam em outros dispositivos.

## Publicar com GitHub Pages

1. Abra Settings → Pages no repositório.
2. Em Build and deployment, escolha Deploy from a branch.
3. Selecione a branch main e a pasta raiz.
4. Salve. O GitHub publicará o site quando o deploy terminar.
