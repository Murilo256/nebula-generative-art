# ✳ NEBULA — Generative Art Lab

> Universos que nunca se repetem.

NEBULA é um laboratório de arte generativa executado diretamente no navegador. Ele transforma partículas, luz e movimento em composições cósmicas únicas — sem frameworks, instalação ou dependências de runtime.

## ✨ Recursos

- **Universos procedurais:** cada geração cria uma nova composição e uma seed identificadora.
- **Quatro paletas:** Aurora Boreal, Nebulosa Violeta, Poeira Estelar e Silêncio Lunar.
- **Controles criativos:** ajuste a densidade de partículas e a intensidade do brilho.
- **Animação:** pause e retome o movimento quando quiser.
- **Interação:** clique na tela para criar ondas de luz.
- **Exportação:** salve sua composição como imagem PNG.
- **Compartilhamento reproduzível:** copie um link que preserva a seed, a paleta, a densidade e o brilho da composição.
- **Sem build:** abra o arquivo index.html ou publique no GitHub Pages.

## 🚀 Como executar

1. Clone ou baixe este repositório.
2. Abra index.html em um navegador moderno.
3. Clique em **Gerar universo** e experimente os controles.

Não é necessário instalar pacotes ou executar um servidor local.

## 🌌 Publicar com GitHub Pages

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch main e a pasta raiz.
4. Salve. O GitHub publicará o site quando o deploy terminar.
